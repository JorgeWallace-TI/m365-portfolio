# Projeto 01 — Intranet Corporativa com Controle de Acesso

## 🔴 Problema
Funcionários de qualquer departamento conseguem acessar 
documentos de outras áreas. Sem controle, sem auditoria.

## ✅ Solução
Intranet corporativa no Microsoft SharePoint com:
- Hub Site central da empresa
- Portal individual por departamento (TI, RH, Financeiro)
- Controle de acesso via grupos do Azure Active Directory
- Cada departamento acessa apenas seu próprio portal

## 🛠️ Tecnologias utilizadas
- Microsoft SharePoint
- Azure Active Directory
- Microsoft Teams
- PowerShell

## 📁 Estrutura do projeto
- /scripts — Scripts PowerShell utilizados
- /docs — Documentação técnica completa
- /prints — Capturas do ambiente configurado
