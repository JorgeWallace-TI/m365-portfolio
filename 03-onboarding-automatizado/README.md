# Projeto 03 — Onboarding Zero Toque

## 🔴 Problema
Novo funcionário chega e passa dias sem acesso
a email, Teams, documentos e sistemas.

## ✅ Solução
Fluxo automático disparado no momento da criação
do usuário no Azure AD:
- Email de boas-vindas personalizado
- Adição automática ao canal correto no Teams
- Acesso liberado no SharePoint pelo departamento
- Tarefa criada no Planner para o gestor

## 🛠️ Tecnologias utilizadas
- Azure Active Directory
- Power Automate
- Exchange Online
- Microsoft Teams
- Microsoft SharePoint
