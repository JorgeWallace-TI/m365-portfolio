# Projeto 05 — Central de Automações

## 🔴 Problema
Equipe perde horas toda semana com tarefas
repetitivas que poderiam ser automáticas.

## ✅ Solução
5 automações prontas com Power Automate:
- Aprovação de documentos no SharePoint
- Relatório semanal automático por email
- Backup de respostas do Forms no SharePoint
- Alerta quando arquivo crítico é modificado
- Notificação automática de vencimento de tarefas

## 🛠️ Tecnologias utilizadas
- Power Automate
- Microsoft SharePoint
- Microsoft Forms
- Exchange Online
- Microsoft Planner
