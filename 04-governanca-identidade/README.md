# Projeto 04 — Governança de Identidade e Acesso

## 🔴 Problema
Ex-funcionário ainda tem acesso a sistemas
meses depois de ter saído da empresa.

## ✅ Solução
Política completa de ciclo de vida de identidade:
- Grupos de segurança por departamento
- Processo de offboarding automatizado
- Auditoria de acessos via PowerShell
- Relatório: quem acessa o quê e desde quando

## 🛠️ Tecnologias utilizadas
- Azure Active Directory
- PowerShell
- Microsoft SharePoint
- Exchange Online
