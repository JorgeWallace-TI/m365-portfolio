# Projeto 02 — Help Desk Automatizado

## 🔴 Problema
Chamados chegam por WhatsApp, email e corredor.
Ninguém sabe o status. SLA não existe.

## ✅ Solução
Sistema de Help Desk interno com:
- Formulário de chamado via Microsoft Forms
- Criação automática de tarefa no Planner
- Notificação imediata ao técnico no Teams
- Email de confirmação automático ao solicitante

## 🛠️ Tecnologias utilizadas
- Microsoft Forms
- Power Automate
- Microsoft Planner
- Microsoft Teams
- Exchange Online
